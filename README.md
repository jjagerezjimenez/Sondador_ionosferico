# Sondador_ionosferico


Estudio y Modelado de Sondador Inosférico mediante Radio Definida por Software (RDS)


1-	Semanas 1-2: Estudio sobre interacciones de Ondas de Radio en Medio Ionosférico.   

                        Estudio de Técnicas de Sondaje Ionosférico. 

		   Estudio de esquemas de Modulación y potencias necesarias para diseño.

2-	Semanas 3-4: Estudio de Plataformas de Hardware para RDS.

3-	Semanas 5-6: Estudio de aplicaciones de software para Radio Definida por Software.

                       Estudio de software para programar plataforma.

4-	Semanas 7-8: Selección de Plataforma de RDS.

5-	Semanas 9-11: Programación de Plataforma seleccionada.

6-	Semanas 12-13: testeo en banco de retardos y ecos sintéticos. 


Nota: Se presentará un informe de avance por cada uno de los cinco (5) primeros puntos.  U
          Se presentará un informe final incluyendo el resultado obtenido en el punto seis (6)
